Reintroducing Werds

September 7, 2026

As I’ve been using SDF2STL, I’ve discovered how nice it is to have a URL start with keys only on the left hand. That way, the URL can be typed while the right hand is still on the mouse. The name for (screaming) was chosen because “screa” can be typed with the left hand.

To continue this trend, words.saej.in will be renamed werds.saej.in and followsfollows.saej.in to bsff.saej.in. The old URLs will still work, but are now redirects.
